# Tic Tac Toe but, numbers!
Ever bored playing tic tac toe? Well be bored even more with this revolutionary new project: 1-2-1!
1-2-1 is an tic tac toe game in which you play tic tac toe against another player offlinely.
It is very boring and short, litteraly just tic tac toe, except there's spooky music for some reason.
